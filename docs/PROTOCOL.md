# 实验协议

## 数据

只使用自录语音或许可证明确允许训练/再分发的语料。原始清单必须包含 `id`、`audio`、`text`、`speaker` 和 `source_recording`。`car-tts prepare` 以“说话人 + 原始录音会话”为组做确定性划分，避免同一次录音的相邻片段跨集合；重复文本会被拒绝。输出的 `metadata.csv` 仅含训练集，并采用 F5-TTS 官方要求的 `audio_file|text` 格式。

记录清洗前后条数、小时数、采样率、声道、拒绝原因、授权来源。禁止把预训练中已出现的数据重新随机划分后描述为未见测试集。

## RTF

`RTF = 生成耗时 / 输出音频时长`。本仓库主指标是端到端 RTF：不含一次性模型加载，包含文本预处理、声学模型、声码器与 WAV 写盘。每次正式测量前预热；CUDA 计时边界同步；固定文本、参考音频、随机种子、NFE、语速、精度和 batch size。汇总使用 `总耗时 / 总音频时长`，避免短句平均造成偏差。

正式实验固定 `warmup=1`、`repeats=3`。每一轮都覆盖完整测试清单，主结果报告三轮 aggregate RTF 的均值与样本标准差，同时保留总耗时除以总音频时长的 pooled aggregate RTF。`benchmark.json` 还保存逐句三次 RTF 的均值与标准差；不能只挑最快一次。三轮使用同一随机种子，因为这里重复的是计时实验，而不是评估生成随机性。

基线与裁剪模型必须在同一进程配置和同一机器上分别测试。报告 PyTorch、CUDA、GPU、NFE、精度和样本数。参数减少不是延迟下降；只有实测 RTF 才称为加速。

## 质量

至少保存全部固定测试文本的输出，不挑样本。建议另跑 ASR CER/WER 和说话人相似度；二者都不能代替自然度 MOS。

自然度盲听采用 1–5 分，隐藏系统名并随机顺序。每个系统使用相同文本；保留匿名原始评分，并报告音频数、听者数、有效评分数、均值和标准差。样本或听者较少时，明确写“小规模主观听测”，不要写成正式大规模 MOS。自动模型评分只能标为 predicted MOS。

RTF 的三次输出不应全部进入 MOS，否则同一句近似重复音频会被重复计权。每个系统从固定的第 0 次输出生成 `mos_samples.jsonl`，每条文本只保留一个样本。建议至少 15 条文本、10 名听者；每位听者对 baseline、equal、global 的相同文本做完全随机化盲听，报告 MOS 均值、标准差和 95% 置信区间。若只有作者本人评分，必须称为“单人主观检查”，不能称为 MOS。

## 激活迁移实验

F5-TTS DiT 每个 FFN 的第一线性层神经元按权重余弦空间做平衡 K-means；每个专家包含相同神经元数。记录 GELU 后激活，对每层专家分数做 Z-score，再跨层选 top-K。与原论文不同，当前实现按一次扩散调用中的 token/ODE step 汇总，并没有把“文本模态/音频模态”当成两个独立输入模态。

专家 profile 必须使用独立校准清单，不能使用最终 RTF/MOS 测试清单。本仓库英文实验使用 `data/profile_texts_en.jsonl` 做激活统计，使用 `data/validation_texts_en.jsonl` 选择保留率和策略，配置锁定后才在 `data/eval_texts_en.jsonl` 上做一次最终测试；后续中文正式实验也应保持同样的 profile/validation/test 隔离。聚类和 profile 固定一次后，所有保留率与 equal/global/random 策略共享同一个 profile，避免为每个结果重新挑选专家。

裁剪使用三种策略：每层等比例激活裁剪（equal）、跨层全局激活裁剪（global），以及层宽匹配随机裁剪（random）。random 先取得 global 在每层的保留专家数量，再以固定 seed 在相应层随机选择同样数量的专家，因此参数量、矩阵形状和逐层宽度均与 global 相同，只移除激活排序这一因素。结构化裁剪同时缩小 FFN 输入投影的输出维和输出投影的输入维，因此确实减少 FFN 参数和矩阵乘法；但 attention、ODE 步数、声码器与 I/O 不变。结论必须同时给出参数量、RTF 和质量退化。
