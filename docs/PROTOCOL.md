# 实验协议

## 数据

只使用自录语音或许可证明确允许训练/再分发的语料。原始清单必须包含 `id`、`audio`、`text`、`speaker` 和 `source_recording`。`car-tts prepare` 以“说话人 + 原始录音会话”为组做确定性划分，避免同一次录音的相邻片段跨集合；重复文本会被拒绝。输出的 `metadata.csv` 仅含训练集，并采用 F5-TTS 官方要求的 `audio_file|text` 格式。

记录清洗前后条数、小时数、采样率、声道、拒绝原因、授权来源。禁止把预训练中已出现的数据重新随机划分后描述为未见测试集。

## RTF

`RTF = 生成耗时 / 输出音频时长`。本仓库主指标是端到端 RTF：不含一次性模型加载，包含文本预处理、声学模型、声码器与 WAV 写盘。每次正式测量前预热；CUDA 计时边界同步；固定文本、参考音频、随机种子、NFE、语速、精度和 batch size。汇总使用 `总耗时 / 总音频时长`，避免短句平均造成偏差。

基线与裁剪模型必须在同一进程配置和同一机器上分别测试。报告 PyTorch、CUDA、GPU、NFE、精度和样本数。参数减少不是延迟下降；只有实测 RTF 才称为加速。

## 质量

至少保存全部固定测试文本的输出，不挑样本。建议另跑 ASR CER/WER 和说话人相似度；二者都不能代替自然度 MOS。

自然度盲听采用 1–5 分，隐藏系统名并随机顺序。每个系统使用相同文本；保留匿名原始评分，并报告音频数、听者数、有效评分数、均值和标准差。样本或听者较少时，明确写“小规模主观听测”，不要写成正式大规模 MOS。自动模型评分只能标为 predicted MOS。

## 激活迁移实验

F5-TTS DiT 每个 FFN 的第一线性层神经元按权重余弦空间做平衡 K-means；每个专家包含相同神经元数。记录 GELU 后激活，对每层专家分数做 Z-score，再跨层选 top-K。与原论文不同，当前实现按一次扩散调用中的 token/ODE step 汇总，并没有把“文本模态/音频模态”当成两个独立输入模态。

裁剪使用两种策略：每层等比例（equal）与跨层全局（global）。结构化裁剪同时缩小 FFN 输入投影的输出维和输出投影的输入维，因此确实减少 FFN 参数和矩阵乘法；但 attention、ODE 步数、声码器与 I/O 不变。结论必须同时给出参数量、RTF 和质量退化。
